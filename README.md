# titanic_Survival_prediction
end-to-end titanic survival predication with randomforest ,feature engineering and gridsearch CV

## Results
- Baseline RandomForest Accuracy: ~80-82%
- Tuned RandomForest Accuracy: ~83-85%
- Top Features: Fare, Sex, Pclass, Title, FamilySize
